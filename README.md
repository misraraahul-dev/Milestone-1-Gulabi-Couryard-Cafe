# Gulabi Courtyard Café

A simple café website created as part of **WS Cube Tech – Milestone 1**.

The website is inspired by Jaipur's pink architecture and welcoming café atmosphere. It is a practice project, not a real café website.

## Pages

- **Home** – Introduction to the café and featured sections
- **About Us** – The café's story
- **Menu** – Food and drinks with images and prices
- **Gallery** – Pictures of the café
- **Contact Us** – Contact details and a message form

## Technologies Used

- HTML5
- Tailwind CSS v4 (CDN)
- Basic CSS
- Google Fonts (DM Sans and DM Serif Display)

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Keep an internet connection to load Tailwind CSS and fonts from their CDNs.

## Note

This is a frontend learning project. The café's contact details are fictional, and the contact form does not send messages without a backend.
